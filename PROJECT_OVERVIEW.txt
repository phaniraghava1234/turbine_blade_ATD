FILE DESCRIPTIONS
─────────────────────────────────────────────────────────────────────────────

1. turbine_blade_design.py (16 KB)
   ─────────────────────────────────
   Purpose: Calculate engine cycle parameters and design turbine stage
   
   Key Features:
   • Brayton cycle analysis for turbojet/turbofan
   • Mean-line turbine stage design
   • Velocity triangle calculations
   • Blade geometry parameters (chord, pitch, stagger)
   
   References:
   • Mattingly - Elements of Propulsion (2006)
   • Mattingly - Aircraft Engine Design (2002)
   • Saravanamuttoo - Gas Turbine Theory (2009)
   • Aungier - Turbine Aerodynamics (2006)
   
   Inputs: Engine type, altitude, Mach number, thrust
   Outputs: turbine_blade_design.json
   
   Usage:
   ```python
   from turbine_blade_design import *
   conditions = EngineOperatingConditions(
       engine_type='turbofan',
       altitude=10668,
       mach_number=0.85,
       thrust_requirement=100000,
       bypass_ratio=9.0
   )
   designer = TurbineBladeDesigner(conditions)
   design = designer.save_design_to_json('output.json')
   ```

─────────────────────────────────────────────────────────────────────────────

2. turbine_blade_geometry.py (7.6 KB)
   ───────────────────────────────────
   Purpose: Generate 3D blade geometry from design parameters
   
   Key Features:
   • NACA-style airfoil generation
   • Radial stacking with twist and lean
   • Free-vortex design
   • Multi-section blade definition
   
   References:
   • Aungier - Turbine Aerodynamics (2006)
   • NACA airfoil theory
   
   Inputs: turbine_blade_design.json
   Outputs: turbine_blade_geometry.json
   
   Usage:
   ```python
   from turbine_blade_geometry import *
   generator = TurbineBladeGeometry('turbine_blade_design.json')
   geometry = generator.save_geometry('geometry.json')
   ```

─────────────────────────────────────────────────────────────────────────────

3. turbine_blade_mesher.py (18 KB)
   ─────────────────────────────────
   Purpose: Generate CFD mesh using gmsh
   
   Key Features:
   • 3D unstructured mesh generation
   • Boundary layer mesh near walls
   • Interactive visualization (Plotly)
   • Mesh quality metrics
   • CGNS and VTK output formats
   
   References:
   • Geuzaine & Remacle - Gmsh (2009)
   • Blazek - CFD Principles (2015)
   
   Inputs: turbine_blade_geometry.json
   Outputs: 
   • turbine_blade.cgns (for solver)
   • turbine_blade_mesh.html (interactive viz)
   • mesh_quality_metrics.json
   
   Usage:
   ```python
   from turbine_blade_mesher import *
   mesher = TurbineBladeMesher('turbine_blade_geometry.json')
   mesher.initialize_gmsh()
   mesher.generate_mesh()
   mesher.save_mesh_cgns('mesh.cgns')
   mesher.create_interactive_visualization('viz.html')
   mesher.finalize()
   ```

─────────────────────────────────────────────────────────────────────────────

4. turbine_cfd_solver.cpp (21 KB)
   ───────────────────────────────
   Purpose: Solve 3D compressible RANS equations
   
   Key Features:
   • 3D Reynolds-Averaged Navier-Stokes solver
   • k-omega SST turbulence model
   • AUSM+ flux scheme (Liou, 1996)
   • Finite volume method
   • Explicit time integration
   
   References:
   • Blazek - CFD Principles (2015)
   • Anderson - CFD Basics (1995)
   • Wilcox - Turbulence Modeling (2006)
   • Menter - k-omega SST (1994)
   • Liou - AUSM+ (1996)
   
   Compilation:
   ```bash
   g++ -std=c++17 -O2 turbine_cfd_solver.cpp -o turbine_solver
   ```
   
   Usage:
   ```bash
   ./turbine_solver turbine_blade.cgns
   ```
   
   Output: turbine_solution.dat

─────────────────────────────────────────────────────────────────────────────

5. turbine_cfd_postprocess.py (17 KB)

   Key Features:

   Inputs: turbine_solution.dat, turbine_blade_design.json
   Outputs:

KEY PARAMETERS REFERENCE
─────────────────────────────────────────────────────────────────────────────

Engine Design:
• OPR (Overall Pressure Ratio): 25-40 (higher for turbofan)
• TIT (Turbine Inlet Temp): 1600-1800 K
• Bypass Ratio: 0 (turbojet), 5-12 (turbofan)

Turbine Stage:
• Loading Coefficient (ψ): 1.5-2.5
• Flow Coefficient (φ): 0.4-0.8
• Degree of Reaction: 0.5 (50% reaction)
• Blade Speed: 300-450 m/s

CFD:
• CFL Number: 0.3-0.8
• Mesh Size: 10,000-1,000,000 cells
• Convergence: Residual < 1e-6

TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────────────

Problem: Mesh generation fails
Solution: Use create_simple_test_mesh() or reduce mesh resolution

Problem: C++ compilation error
Solution: Install g++, check C++17 support, or skip solver (use synthetic data)

Problem: Solver doesn't converge
Solution: Reduce CFL, improve mesh quality, check boundary conditions

Problem: Import errors
Solution: Install missing packages: pip install [package_name]

Problem: Visualizations don't display
Solution: Open HTML files directly in browser, not in IDE
